# dev-test

Development and test addons for Odoo 18.0, maintained by [OCA-Finland](https://github.com/OCA-Finland/dev-test).

Branch naming: `{version}-{desc}`, for example `18.0-dev`.

## Addons

- `account_period_close` — close income, expense, and VAT accounts between two dates
- `account_vat_periods` — VAT period closing and Finnish Vero API filing
- `l10n_fi_payroll_community` — Finnish payroll for Odoo Community
