## Security: Encryption Key Setup

This module encrypts credentials using Fernet symmetric encryption. Before installing the module, a valid
encryption key must be present in `odoo.conf`:
- generate a key
    ```bash
    python3 -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
    ```
- add to `odoo.conf`:
    ```ini
    banking_encryption_key = <your-generated-key>
    ```
- restart Odoo


## OP Corporate API

### Prerequisites
- A Corporate API contract in OP API Admin.

### Credentials

| Credential | Where it comes from |
|---|---|---|
| Client ID | OP API Admin |
| Client Secret | OP API Admin |
| mTLS private key | generated by you (RSA, PEM) |
| mTLS certificate | OP API Admin: upload a CSR made from your mTLS key, download the certificate (X.509, PEM) |
| Payment signing key | generated by you (RSA, PEM) |
| Payment signing KID | OP API Admin: issued after you submit a CSR made from your signing key |

Generate each key and its CSR with OpenSSL; exact steps are in the
[OP Corporate Payment API docs](https://op-developer.fi/products/banking/docs/op-corporate-payment-api).
Client ID, Client Secret and private keys must never be shared or exposed.
